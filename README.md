# SecureLab

## Дэлгэрүүлсэн сургалт

10 сэдэв тус бүр Онол → Case → Шалгалт бүтэцтэй: 6 онолын хэсэг, 5 кейс, 4 асуулт. Шинээр Clean desk / биет баримт, гар утас ба зөөврийн төхөөрөмж, программын шинэчлэлт, нөөцлөлтийн дадал нэмэгдсэн. 50% ба түүнээс дээш бол тэнцсэн, 50%-иас бага бол тэнцсэнгүй. Бүх оролдлогыг хадгалж, “Дуусгасан” хэсэгт сүүлийн оноо, оролдлогын тоог харуулна. Өмнөх дүүргэлт хадгалагдана; хуучин оноо байхгүй бол зохиомол оноо харуулахгүй.

Агуулгын шинэчлэлт сервер асахад нэг удаагийн migration-аар орно. Унших, дасгал хийх хугацаа сэдэв тус бүр ойролцоогоор 25–30 минут. Сэдвийн зургууд public/images дотор хадгалагдана.

Шалгах: `node server/verify-curriculum.js` — тусдаа түр local сан дээр API, онооны босго, ахиц хадгалалтыг шалгана.

Монгол хэл дээрх мэдээллийн аюулгүй байдлын интерактив сургалтын веб апп.

## Ажиллуулах

```bash
npm install
npm run dev
```

Дараа нь `http://localhost:5173` хаягийг нээнэ. Frontend нь Vite (5173), API нь Express (3001) дээр ажиллана.

Production хувилбар:

```bash
npm run build
npm start
```

`http://localhost:3001` хаягийг нээнэ.

## Технологи

- React + Vite
- Express
- PostgreSQL (`pg`) production орчинд
- SQLite (`better-sqlite3`) зөвхөн local fallback/test-д
- JWT нэвтрэлт, bcrypt нууц үгийн hash

Production орчинд `JWT_SECRET` environment variable-ийг заавал өөрийн нууц утгаар тохируулна.

## PostgreSQL тохиргоо

300+ хэрэглэгчтэй production орчинд `DATABASE_URL` тохируулбал сервер PostgreSQL ашиглана. `DATABASE_URL` байхгүй үед local SQLite fallback ажиллана.

Жишээ:

```bash
DATABASE_URL=postgres://USER:PASSWORD@HOST:5432/securelab
JWT_SECRET=маш-урт-нууц-key
npm run build
npm start
```

SSL шаарддаг managed database ашиглаж байвал:

```bash
DATABASE_SSL=true
```

Connection pool:

```bash
DB_POOL_MAX=20
```

Сервер асах үед PostgreSQL table-үүд автоматаар үүснэ:

- `users`
- `lessons`
- `progress`
- `exam_attempts`
- `login_events`
- `lesson_views`
- `news`
- `curriculum_migrations`

PDF болон upload хийсэн сургалтын зураг database-д хадгалагдана. 300+ хэрэглэгчийн хувьд backup-ийг тогтмол хийх хэрэгтэй:

```bash
pg_dump "$DATABASE_URL" > securelab-backup.sql
```

## Publish хийх санал

PostgreSQL хувилбарыг Render, Railway, Fly.io эсвэл VPS дээр deploy хийхэд тохиромжтой.

Render/Railway дээр:

1. GitHub repository холбоно.
2. PostgreSQL database үүсгэнэ.
3. Web service үүсгээд environment variables тохируулна:
   - `DATABASE_URL`
   - `DATABASE_SSL=true` managed SSL шаардвал
   - `JWT_SECRET`
   - `NODE_ENV=production`
4. Build command:
   `npm install && npm run build`
5. Start command:
   `npm start`

VPS дээр:

1. Node.js 20+ болон PostgreSQL суулгана.
2. Database/user үүсгэнэ.
3. `.env` эсвэл process manager дээр `DATABASE_URL`, `JWT_SECRET` тохируулна.
4. `npm install && npm run build && npm start`.
5. Nginx reverse proxy ашиглаж HTTPS сертификат холбоно.

## Админ панел

Суралцагч зүүн цэсний доод талын “Нууц үг солих” товчоор одоогийн нууц үгээ баталгаажуулж, шинэ нууц үгээ хоёр удаа оруулна. 8-аас доошгүй тэмдэгттэй, хуучнаасаа өөр нууц үг шаардлагатай. Амжилттай солигдвол бүх хуучин нэвтрэлт хүчингүй болж, шинэ нууц үгээр дахин нэвтэрнэ. Гар утсанд цэсийг нээж энэ товчид хандана.

Хэрэглэгчийн мөрөн дэх цоожны товчоор шинэ нууц үг өгнө (8-аас доошгүй тэмдэгт, bcrypt-ийн 72 байтын хязгаар). Шинэчлэхэд хуучин нэвтрэлтүүд хүчингүй болно. Өөрийн нууц үгийг сольсон админ дахин нэвтэрнэ. Сервер дахин асахад өөрчилсөн нууц үг хадгалагдана.

“Мэдээ мэдээлэл” хэсгээс админ хийсэн ажил, төлөвлөгөө, зөвлөмж нийтэлж, засаж, устгана. Нийтлэл бүр гарчиг, хариуцсан мэргэжилтэн, ангилал, тайлбар болон сонголтоор PDF хавсралттай. PDF 8 MB хүртэл бөгөөд SQLite санд хадгалагдана. Нэвтэрсэн хэрэглэгч цэснээс нийтлэлийг уншиж, PDF-ийг татна. Өгөгдлийн санг нөөцлөхөд мэдээ, хавсралт хамт нөөцлөгдөнө.

Хяналтын самбарт бүртгэлтэй болон нэвтэрсэн суралцагч, 7 хоногийн хандалт, нээсэн сургалт, шалгалтын оролдлого, тэнцсэн оролдлогын хувь харагдана. Хэрэглэгчийн мөрийг дэлгэж хичээл тус бүрийн сүүлийн/шилдэг оноо, огноо, бүх оролдлогыг харна. “Шинэчлэх” товч тайланг дахин уншина.

Хандалтын түүх шинэчлэл суулгаснаас эхэлнэ; өмнөх нэвтрэлт, үзэлтийг нөхөж тооцохгүй. Нээсэн сургалт нь уншиж дуусгасны баталгаа биш. Ерөнхий статистикт админ орохгүй. Хэрэглэгчийн дэлгэрэнгүй хэсэгт эрхээр шүүж болно. Өдрийн хандалтыг UTC өдрөөр, огноог браузерын цагийн бүсээр харуулна.
